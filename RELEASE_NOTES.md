# Release Notes

Version v3.0.4 — August 20, 2026

## Fixes
- Dodge label now defaults to "Dodge" when the skill map has no name for the dodge action (skill id 23275). This makes your usage data easier to read.
- NOTE: This only applies to new uploads; existing reports won't be retroactively updated.

## QoL Improvements
- When the dodge action isn’t named in the skill map, you’ll get a clear, readable label in skill usage data instead of a generic placeholder.
