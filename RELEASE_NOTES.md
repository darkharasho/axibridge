# Release Notes

Version v3.10.3 — September 14, 2026

## Fights now sort newest first, everywhere

Every fight list, tab, and picker across the app now shows the newest fight first instead of last. That covers Fight Breakdown, Fight Comp, Squad Comp By Fight, Commander Stats, and the CC/Strip Timeline pickers — plus the Pin Pressure table. Fight Diff Mode now defaults B to the newest fight and A to the one right before it, so you're comparing the latest pull by default instead of the oldest.

The CC/Strip timelines are now sorted by actual fight start time, and Map Replay picks the newest fight by start time (not upload time) and keeps following new fights as they come in. The commander rollup sparkline also orders fights by start time now.

NOTE: charts are unchanged, and already-published web reports keep their old fight order until you republish them.
