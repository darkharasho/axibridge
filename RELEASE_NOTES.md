# Release Notes

Version v3.7.2 — September 8, 2026

## Druid cleanse numbers now match arcdps

Cleanses done by your pet weren't being counted. Every other class lined up with the in-game meter exactly, but druids were reading 30-40% low because a ranger pet is basically the only minion that cleanses in any volume — so the missing bucket only ever showed up on one profession.

Pet cleanses are now credited to their owner, the way arcdps does it. Across a night of real logs this moved one druid from 1146 to 1581 and left everyone else's number untouched.

NOTE: This applies to anything you look at from here on, including old logs — the numbers are recomputed, not stored, so re-opening a past report will show the corrected total. Reports already published to the web keep whatever they were built with until you re-publish them.

Thanks to Mignon for the report and the side-by-side screenshots.
