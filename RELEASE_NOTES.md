# Release Notes

Version v3.25.0 — November 11, 2026

## Which Skills Gave Each Boon
- In Boon Output, pick a boon and click a player to see which of their skills gave it. For example, Firebrand Resistance splits into Symbol of Luminance, Chapter 4: Stalwart Stand, and so on, each with its share.
- This is an estimate. arcdps doesn't record which skill applied a boon, so AxiBridge works it out from cast timing. Traits, relics and anything it can't match always show up in an "Other (traits, relics, unmatched)" row, often a third or more of the total.

NOTE: Only works on logs from arcdps builds after the May buff change. It won't apply retroactively: to see it on logs you already have, re-import the log files.
