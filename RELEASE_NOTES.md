# Release Notes

Version v3.7.3 — September 8, 2026

## Select All in History

Manage mode in Report History now has a Select All button. It picks up everything currently on screen, so if you've narrowed things down with the search box or a commander filter, it only grabs those. Deselect All works the same way — it clears what you can see and leaves anything hidden behind a filter alone.

## Fixes

- The "X reports selected" bar at the bottom of History had no background at all. On most themes you couldn't tell, but on Glass the report cards scrolled right through it. It's solid now.
