# Release Notes

Version v3.17.1 — September 23, 2026

## Visual fixes

The desktop shell (app content, dashboard rail, titlebar) now sits properly on the dark axi background instead of floating a shade too light. A handful of design rules that were quietly losing to inline styles are back in effect.

Published web reports also got a fix: the page background was painting at the wrong brightness level, so it now matches the rest of the app.

## Fixes

- Toned down the gold accent on the stats search icon and the report trophy badge so they're less loud.
- The report header no longer repeats "Statistics Dashboard" twice.
