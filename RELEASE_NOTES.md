# Release Notes

Version v2.17.0 — August 7, 2026

## Damage Mitigation in Discord Embeds

By request: fight embeds can now include a Damage Mitigation top 10. Turn it on in Settings under the Discord embed stats (it's off by default with the other extra stats). It runs the exact same math as the dashboard's Damage Mitigation section, scoped to each fight, so the embed and the dashboard will always agree.

NOTE: Mitigation is an estimate — avoided hits valued at the enemy skill's average damage — so it won't match the arcdps meter, and that's expected.
