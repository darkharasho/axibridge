# Release Notes

Version v3.10.1 — September 13, 2026

## Fixes
- Boon Uptime charts now use exact per-fight uptime instead of an approximation, so the numbers you see match what actually happened in each fight.
- The Boon Uptime summary now shows "Overall" instead of "Peak" — it was always the time-weighted average across your attended fights, not your single best fight, and the old label made it look wrong when it read lower than the per-fight average.
- Boon Output now labels its uptime column "Uptime / Member" for group and squad boons, since that number is what you alone gave each recipient on average, not the squad's overall uptime.
- Conjured Amalgamate encounters are no longer mislabeled as Red Borderlands — map name matching now requires a whole-word match instead of a loose substring check.
