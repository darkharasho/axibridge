# Release Notes

Version v2.11.0 — June 20, 2026

## Boon Strip comparison chart

A new Boon Strips section in the Defense group: a diverging chart comparing boon strips across the squad, built on real per-fight boon-applied counts. It slots in next to the rest of the Defense breakdown so you can see at a glance who's pulling their weight on strips.

## Your replay data now powers positional analysis

The shared metrics package gained positional analysis — squad cohesion, overextension, out-of-position deaths, death geography, and commander pathing — that AxiVale reads to review WvW fights by *where people were*. Make sure your reports include combat-replay data (precise replay) to get the most from it.

## Fixes

- Replay-less reports are no longer published during worker aggregation, so the replay/position data stays intact for downstream analysis.
- Chart tooltips and hover states now use solid backgrounds under the glass theme — no more see-through hovers.
