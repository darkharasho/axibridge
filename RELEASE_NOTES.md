# Release Notes

Version v3.17.4 — September 25, 2026

## Fight Breakdown now shows a dps.report link too

Every row in the Fight Breakdown table has a new far-right column with a direct link to dps.report, alongside your AxiBridge share link. You no longer have to pick one or the other — both are right there. This applies on the desktop app and in published web reports.

## dps.report uploads no longer stop once sharing is set up

Logs now keep uploading to dps.report even after you've configured AxiBridge share links, since that's what feeds the new column above. "Also upload to dps.report" in Settings is now the only way to turn this off — flip it off if you don't want your logs going to dps.report at all.

NOTE: this only affects fights parsed from here on; older fights won't retroactively get a dps.report link unless they already had one.
